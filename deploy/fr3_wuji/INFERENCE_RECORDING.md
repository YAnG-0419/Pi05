# 真实观测推理记录

`record_inference.py` 将现场三路 RGB 和 54 维实测状态发送到本机模型服务，保存原始 `(50, 54)` 绝对关节目标及诊断。该入口没有 ROS 动作发布器或手部写接口，不裁剪输出，不执行动作。

2026-09-08 已完成 30 秒、157 次现场推理。发现左臂第 7 关节越界、首步跳变及全部请求返回时原输入超过 200 ms；详见 [本机实测报告](../../logs/fr3_wuji/inference-real-20260908-01/README.md)。

同日延迟优化后，30 秒完成 147 次推理，返回时原输入年龄中位数 157.74 ms、最大 183.28 ms，0 次超过 200 ms；详见 [延迟验收报告](../../logs/fr3_wuji/inference-latency-20260908-01/README.md)。跳变与真机执行验收仍未完成。

## 运行

先按 [模型服务说明](README.md) 启动 checkpoint，再用 `smoke_test.py` 预热 JAX。预热用假观测，记录与真实观测分开。默认真实响应超时 20 秒；不要让首次编译混进稳态延迟测量。

没有其他硬件所有者时：

```bash
bash deploy/fr3_wuji/run.sh deploy/fr3_wuji/record_inference.py \
  --arm-source direct --hand-source sdk --start-cameras \
  --duration 30 --output logs/fr3_wuji/inference-real-new
```

2026-09-08 延迟优化后，该入口在 `--start-cameras` 时默认选择 `--camera-profile rgb`：为本次运行生成独立 YAML，关闭深度流、SDK 帧同步与帧聚合；三路 RGB 的身份、尺寸、帧率、全局源时间戳及曝光配置沿用原配置。文件保存在输出目录的 `camera-config/`，原遥操配置不作修改。

默认每 5 ms 检查一次新观测，发送前要求**整组样本年龄最多 70 ms**（`--max-input-age 0.07`），为模型往返预留余量。这是比原 200 ms 更严格的发送预算，过旧的候选观测会跳过，等下一组新输入。**返回时仍按原 200 ms 判定过期**，预算不保证任何一次异常慢响应都能及时返回。

需要复现优化前设置时，显式指定 `--camera-profile recording --poll-interval 0.0333333333 --max-input-age 0.2`。这些参数用于诊断对比，不是执行许可。

已有遥操提供状态和图像时，使用默认的 ROS 订阅模式，省略三个硬件源参数。既有进程不由本入口启停。输出目录必须是新目录。采集使用 [观测适配器](OBSERVATIONS.md) 的既有进程清理和时效规则，结束后关闭本次创建的采集进程；模型服务由启动它的终端管理。

ROS 订阅模式不会自动调整外部相机生产者；如果外部输入达不到 70 ms 发送预算，会记录跳过或推理次数不足，不能把生产者的延迟隐藏掉。

## 检查内容

- **输入时效**：保留 200 ms 样本年龄、150 ms 最新关节反馈、80 ms 组内时间跨度限制。序列化后、发送前再次检查年龄和最新状态。过期输入不发送。
- **返回时效**：用发送时样本年龄加单调时钟测得的往返延迟计算原输入年龄，检查是否超过 200 ms。另检查返回时最新四组关节反馈，记录首步相对这时实际位置的差值。相机过期不妨碍独立检查关节反馈。时钟跳变不会把旧输入变新。
- **关节范围**：按名字读取原安全网关的 FR3 限位，以及原配置指定的 Hand 2 URDF 限位。保存源文件 SHA256。手部检查依据模型配置，未读取固件实际限位。
- **跳变**：分别报告首步相对图像对齐状态、发送时最新状态和返回时最新状态的最大绝对差；另报告整个 horizon 相对输入状态的最大差。机械臂以现有网关 `max_initial_delta=0.05 rad` 为诊断阈值。手部仅报告差值，尚未确定接管阈值。
- **相邻动作**：记录相邻步差值及按训练 30 Hz 推算的速度。FR3 对比现有网关的 0.7 rad/s，手部对比 URDF 速度。这里没有执行或模拟网关限速。
- **延迟**：往返包括发送、模型处理及接收，不包括磁盘保存时间；同时记录服务端耗时。循环每次只处理一条请求，持续更新的观测缓存由独立线程接收。
- **分段诊断**：记录图像进入 ROS 回调的时刻、源数据进入观测缓存时的年龄、缓存等待、最新数据及最终选中样本的年龄；另记录请求序列化和 NPZ 保存耗时。源时间戳不会改成接收时间。

## 输出

| 文件 | 内容 |
| --- | --- |
| `inference-report.json` | 次数、延迟分位数、过期计数、分组诊断、限值及来源 |
| `inferences.jsonl` | 每次请求的时间元数据、状态年龄、跳变及超限诊断 |
| `inference-*.npz` | 每次真实模型输入、原始动作、发送及返回时最新状态 |
| `joint-ranges.csv` | 全部 54 个关节的限位、输出最小/最大值和超限数量 |
| `report.json` | 观测采集、拒绝及数据源统计 |

`state_at_return` 为空数组表示当时没有可用的新鲜反馈，不以旧状态代替。输入与输出按相同序号关联。磁盘记录仅供离线分析。

`status=recorded` 只表示至少完成十次真实推理并正常结束，不表示输出通过执行验收。越界、跳变和返回时输入过期会如实保留，不为取得“通过”而放宽限制。该检查不评估碰撞、接触力或闭环任务成功率。

离线检查：

```bash
env -u PYTHONPATH -u PYTHONHOME \
  PYTHONDONTWRITEBYTECODE=1 PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 JAX_PLATFORMS=cpu \
  .venv/bin/python -m pytest deploy/fr3_wuji/test_observation.py deploy/fr3_wuji/test_record_inference.py -q
```
