# FR3/Wuji 影子客户端

2026-09-08：第一阶段软件核心已实现。可以重放现有记录，或读取真实观测并请求模型，检查动作、记录拒绝原因。**本版本没有向机械臂或手发送命令的入口。** ROS 命令桥、手部执行拥有者、最后消费端期限保护和硬件停止验收仍属后续阶段。

## 已实现的行为

- 固定 54 维顺序、50 步绝对关节目标；不可变消息携带请求编号、会话代次和原始观测期限。机械臂命令名映射单独验证，不重复累加当前位置。
- 状态机包含观察、准备、接管、单步、暂停、故障。暂停立即清空候选并更新代次；恢复只重新准备，旧响应不能恢复输出；故障不会自动恢复。
- 候选队列容量为 1，拒绝重复/乱序请求。检查全块限位、首步与最新实测位置的偏差、反馈和原始观测期限。记录块内按 30 Hz 计算的速度，不把 50 步全部排队执行。
- 机械臂首步阈值维持 `0.05 rad`。手部阈值未知，默认报告 `hand_acquisition_unconfigured` 并拒绝接管。
- 显式影子单步先完成接管检查，再计算一个按 10 ms 速度限幅的内存目标，然后暂停。不能通过限幅把超阈值首步变成“已通过接管”。影子接收端再次检查代次、顺序和期限；没有硬件发布器。
- 现场模式每次最多一个推理请求，WebSocket 推理在独立进程，观测主循环继续轮询和处理暂停。IPC 和序列化之后再次检查发送时观测年龄不超过 70 ms，结果仍使用原始 200 ms 期限；最新反馈不超过 150 ms。
- 压缩图像和事件写盘在独立进程。有界图像队列满时丢弃并计数，关键事件队列满或日志进程失败会报错、锁存客户端故障并退出。

`READY` 表示软件可检查候选；`accepted` 仅表示影子接管检查通过；`shadow_frames_submitted` 仅统计内存目标。它们都不代表硬件命令已接受、已运动或已到位。

## 离线重放

在项目根目录运行，输出目录须不存在：

```bash
bash deploy/fr3_wuji/run.sh deploy/fr3_wuji/client.py replay \
  --source logs/fr3_wuji/inference-latency-20260908-01 \
  --output logs/fr3_wuji/client-replay-new
```

读取 `record_inference.py` 保存的 `inferences.jsonl` / `inference-*.npz`，按记录的相对时间检查每块的假设首步，不连接模型或设备。当前重放入口支持这种旧记录格式；现场客户端自身的 `events.jsonl` / `sample-*.npz` 用于诊断，尚未接入同一重放入口。

可追加 `--inject late_response`、`--inject feedback_loss` 或 `--inject pause_before_response`。输出 `events.jsonl` 和 `summary.json`，记录每次拒绝原因。重放结果的期限使用虚拟时钟，不得用于硬件输出。

## 现场只读入口

先按 [README](README.md) 启动模型服务，并运行 `smoke_test.py` 完成首次 JIT 预热。现场客户端的单次推理超时为 2 秒，预热不能占用第一次真实请求。

```bash
bash deploy/fr3_wuji/run.sh deploy/fr3_wuji/client.py live-shadow \
  --arm-source direct --hand-source sdk --start-cameras \
  --duration 30 --output logs/fr3_wuji/client-live-shadow-new
```

复用已有只读生产者与占用检查，默认使用已测过的 RGB 相机配置。源数据采集/硬件依赖与 [OBSERVATIONS](OBSERVATIONS.md) 相同；不会调用手部使能或关节发送接口。新客户端增加了进程间传输，之前测得的 158 ms 左右年龄不能代替新入口的现场延迟验收。

默认只检查并记录。如追加 `--single-shadow-step`，在第一条可尝试的结果上请求一次影子单步；首步检查不通过则记录拒绝，不反复自动尝试。当前手部阈值未配置，默认不能生成该目标。

启动行打印客户端自身 PID。运行中可向该 PID 发送 `SIGUSR1` 暂停、`SIGUSR2` 重新准备；重新准备不会自动申请影子单步。`Ctrl-C` 终止并清理本次子进程。相机首次预热 35 秒期间尚未开始影子主循环，暂停请求在预热后处理。暂停不关闭只读采集；已发出的推理可以返回，但旧代次结果被拒绝。这里只确认软件停止，不代表未来硬件的停止行为已经验收。

输出包括 `events.jsonl`、`sample-*.npz`、`client-report.json` 及原观测采集报告。事件保存原始预测的检查结论、输入元数据、模型往返时间、返回 IPC 延迟和评估时观测年龄；NPZ 保存原图、观测状态、原始预测及评估时实测状态。退出时未完成推理会丢弃并在报告中标记。
